The problem
Every block on Arc has a random value of zero. Without real randomness, contracts can't run lotteries, raffles or fair allocations.
The solution
drand is a network of universities and companies that publishes a signed random number every 3 seconds. ArcDraw pins a future round and checks its BLS signature inside the contract, using Arc's built-in BLS12-381 precompiles.

Click "Request draw". The contract will pin a round that hasn't happened yet.

  • Why it's fair.The round is chosen before it exists. Neither the requester nor the operator knows the result.
  • Who delivers it.Anyone can bring the proof to the contract and earn an optional USDC bounty.
  • What it costs.Verifying the proof onchain costs about 0.006 USDC.
  • Who can check.Anyone can redo the math with the same signature and get the same winners.

What's built

An open-source, MIT-licensed building block. The rules live in the contract. The rest helps apps and people use them.
